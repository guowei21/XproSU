# 使用手册

## 一、运行前

- 每次完整运行前先**重启手机**，清掉上一轮残留的内核状态；
- 打开「开发者选项 › 无线调试」，首次需要配对，之后同一密钥可自动重连；
- 如果要接管 KernelSU：先装好对应的管理器 APK，模块由 late-load 加载。

## 二、运行步骤

1. 打开应用点「连接（无线 ADB）」：密钥已授信时自动发现端口直连；
2. 首次配对：点「用配对码重新配对」，去设置里点「使用配对码配对设备」，
   把 6 位码填进应用弹窗；
3. 选择 Root 管理器，保持「自动检测」即可；
4. 按需打开「安全模式」；
5. 点「一键越狱」，等待 12 个阶段走完；
6. 成功后模块加载，应用会自动拉起管理器。

## 三、支持机型（内置偏移）

- PD2506 / V2506（Y500）：16.1.15.0、16.1.13.2
- PD2516 / V2516（Y500 Pro）：16.1.11.0
- PD2307 / PD2329 / V2307（iQOO 12）：16.2.11、16.2.20.3、16.2.20.7、16.2.21.1
- PD2417 / V2417（Z9 Turbo+）：16.2.14.1
- PD2324 / V2324A / V2324HA / V2324H / PD2324J（X100 系列）：16.2.12.0、16.2.13.1

列表内机型已内置 KSU 交接所需的对象地址，无需解析。

## 四、列表外的 build

点「解析偏移」，用系统文件选择器选中该机型的 boot.img，生成 `/data/local/tmp/ic-syms.txt` 后再运行。

## 五、安全模式

勾选后，提权时会禁用全部 KSU 模块（通过管理器自带的 ksud 交接脚本完成）。重启后模块恢复正常。

## 六、清理与善后

- 每次运行结束会自动清理本工具的临时文件与日志副本；
- 提权用的 ksud 暂存在 /data/local/tmp，由自动清理回收；/data/adb/ksu 只由安装流程写入，不删内容；
- 运行后残留的 ic-timer 进程**不能 kill -9**，只能重启清理；
- 已加载的内核模块要重启后才消失。
